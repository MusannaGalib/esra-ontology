# ESRA ontology

The terms of the ESRA namespace, `https://data.energystoragera.org/ns#`, used by the ESRA data platform of the
Energy Storage Research Alliance: the classes, properties and links of the working graph, the vocabulary of the
semantic layer, and the terms a person reviewed and approved.

- **Files:** [`esra.ttl`](esra.ttl) (Turtle, OWL) and [`esra.jsonld`](esra.jsonld). 262 terms in version 2026-11-17:
  235 defined by ESRA and 27 that give a standard term the name ESRA's records use. Every `esra:` address
  in the platform's released knowledge graphs is defined here.
- **Live:** `https://data.energystoragera.org/ns` (Turtle, JSON-LD or a readable page, by content negotiation).
- **Versions:** each release is a git tag `v<date>`, matching the file's `owl:versionInfo`;
  `https://data.energystoragera.org/ns/<date>` serves the current one and redirects an older one to its tag.
- **Source:** generated by `Data_pipeline/ontology/build_esra_ttl.py` in the ESRA platform from its ontology files;
  do not edit `esra.ttl` by hand.
- **Links to other ontologies:** a class that is a kind of an EMMO, BattINFO, CHAMEO or schema.org class says so
  with `rdfs:subClassOf` (never `owl:equivalentClass`); a property with the same meaning as a standard one uses
  `rdfs:subPropertyOf`, a related one `rdfs:seeAlso`; a quantity names its standard term with `schema:propertyID`.
- **Definitions:** every term has a `skos:definition`.
- **Cite:** see [`CITATION.cff`](CITATION.cff).
